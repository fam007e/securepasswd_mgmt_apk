SecurePasswd MGMT is a highly secure, open-source Password and TOTP manager for Android, built as a native port of the SecurePasswd_MGMT desktop suite.

<b>Key Features & Security:</b>
- <b>Military-Grade Security:</b> Employs <b>Argon2id</b> for key derivation (128MB memory cost) and <b>SQLCipher</b> for transparent, 256-bit AES database encryption.
- <b>Native Core:</b> Uses the same high-performance C core as its desktop counterpart for 100% security parity and identical entropy.
- <b>Cryptographic Foundation:</b> Powered by <b>OpenSSL</b> and <b>libsodium</b> primitives for robust, industry-standard security.
- <b>Privacy First:</b> Sensitive data is handled in ByteArrays and explicitly zeroed in memory after use. No immutable strings are used for secrets.
- <b>Zero-Knowledge:</b> No telemetry, no tracking, and no unexpected network calls. Your data stays in your control.
- <b>Password Health:</b> Privacy-preserving k-anonymity checks via Have I Been Pwned (HIBP) API.
- <b>Local Sync:</b> Secure, authenticated vault synchronization for cross-device usage.
- <b>Modern Interface:</b> A sleek and intuitive experience built with <b>Jetpack Compose</b> and Material 3.

This project is made possible by the incredible work of the open-source community, utilizing <b>Argon2</b>, <b>OpenSSL</b>, <b>SQLCipher</b>, <b>ZXing</b>, and <b>CMake</b> to deliver a high-quality security tool.
